# SQL Analysis

## Overview

This folder contains the SQL analysis performed for the Indian Superstore Sales Analysis Dashboard project.

PostgreSQL was used to analyze the sales dataset, perform database operations, answer business questions, and generate analytical insights.

## SQL File

- `Indian_Superstore_SQL_Queries.sql`

The SQL file contains the complete analysis performed on the Indian Superstore sales data.

## Database Design

The project uses a normalized database structure containing:

- Customers
- Products
- Locations
- Orders
- Sales

Primary keys and foreign keys were used to establish relationships between the tables.

Created Indexes for query optimizations.

## SQL Analysis Areas

The analysis covers:

- Data validation
- Exploratory data analysis
- Customer analysis
- Product analysis
- Regional analysis
- Sales analysis
- Profit analysis
- Order analysis
- Business performance analysis
