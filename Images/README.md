# Project Images

## Overview

This folder contains visual assets related to the Indian Superstore Sales Analysis Dashboard project.

## Dashboard Preview

- `Indian_Superstore_Dashboard.png`

The dashboard image provides a visual preview of the final interactive Excel dashboard.

## Dashboard Contents

The dashboard includes:

- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Total Orders KPI
- Profit Margin KPI
- Sales Trend by Year
- Sales by Region
- Sales by Outlet Type
- Profit by Region
- Quantity by Ship Mode
- Profit by Ship Mode
- Profit by Outlet Type
- Top 10 Products by Sales
- Top 10 Products by Profit

## Interactive Filters

The dashboard includes slicers for:

- Year
- Region
- Ship Mode
- Outlet Type

## Purpose

The image is included to provide a quick visual representation of the final dashboard and make the project easier to understand when viewed on GitHub.
