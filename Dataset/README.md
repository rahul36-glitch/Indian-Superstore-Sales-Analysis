# Indian Superstore Sales Dataset

## Dataset Overview

This folder contains the dataset used for the Indian Superstore Sales Analysis Dashboard project.

The dataset contains 100,000 sales records and 26 columns covering customer, product, order, location, sales, quantity, discount, profit and shipping information.

## Tools Used

- PostgreSQL
- SQL
- Microsoft Excel

## Project

This dataset is part of this:

**Indian Superstore Sales Analysis Dashboard**

The project uses SQL for data analysis and Excel for dashboard development and visualization.
