# Excel Dashboard

## Overview

This folder contains the Microsoft Excel dashboard developed for the Indian Superstore Sales Analysis project.

Excel was used to transform the SQL analysis into an interactive dashboard that allows users to explore sales and profitability across different business dimensions.

## Excel File

- `Indian_Superstore_Sales_Analysis.xlsx`

## Dashboard KPIs

The dashboard contains five key performance indicators:

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Profit Margin

## Dashboard Visualizations

The dashboard contains the following visualizations:

1. Sales Trend by Year
2. Sales by Region
3. Sales by Outlet Type
4. Profit by Region
5. Quantity by Ship Mode
6. Profit by Ship Mode
7. Profit by Outlet Type
8. Top 10 Products by Sales
9. Top 10 Products by Profit

## Interactive Slicers

The dashboard includes four interactive slicers:

- Year
- Region
- Ship Mode
- Outlet Type

These slicers allow users to filter the dashboard and interactively explore the data.

## Excel Features Used

- PivotTables
- PivotCharts
- Slicers
- KPI calculations
- Data visualization
- Interactive dashboard design

## Dashboard Purpose

The dashboard was developed to provide a clear visual view of:

- Sales performance
- Profit performance
- Yearly trends
- Regional performance
- Outlet performance
- Shipping performance
- Product performance

## Project Outcome

The Excel dashboard converts the results of the SQL analysis into an interactive visual reporting tool that can support business analysis and decision-making.
